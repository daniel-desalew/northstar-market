# AmazonStore

AmazonStore is organized as a React/Vite frontend in `client/` and an Express
backend in `server/`.

## Getting started

Install dependencies in `client/` and `server/` with `npm install` from each
directory. Copy the relevant `.env.example` file to `.env` and configure the
required values. Start the frontend with `npm run dev` from `client/`.

The server and storefront feature modules in this scaffold are structural
placeholders; backend startup and application features still need to be
implemented.
